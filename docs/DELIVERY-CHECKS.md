# Проверка комплекта 23.11.2026

Виджет собран из копии передаваемых исходников на Node.js **24.22.3**, Vite **8.0.14**. Сборка завершена успешно: 15 модулей, выходной `widget/app.js` около 266,80 kB. Архив виджета сформирован bestzip **3.0.1**.

В окружении подготовки команда npm недоступна, поэтому выполнены эквивалентные шаги скрипта `build`: вызов `vite/bin/vite.js build`, затем `bestzip/bin/cli.js ../widget.zip '*'` из папки widget. Использованы уже установленные локальные зависимости; свежая установка зависимостей через `npm ci` **не проверена**. В комплект входят `package.json` и lock-файл для её повторения на машине разработчика.

При финализации инструмент проверяет:

- Размер и SHA-256 нового CFE по исходному манифесту.
- SHA-256 пяти BSL-модулей и наличие их точных байтов внутри CFE.
- Целостность ZIP виджета и обязательные файлы его корня.
- Четыре успешных сохранённых результата цены/договора и четырнадцать результатов регрессий.
- Целостность итогового архива и контрольные суммы передаваемых файлов.

Эти проверки подтверждают состав комплекта. Исполнение на платформе 1С, доступность публикации, workflows n8n и установка в amoCRM при подготовке архива не повторялись. Результаты runtime относятся к 26.10.2026.
