# Эксплуатация и диагностика

## Перед обновлением

Сохраните резервную копию базы и текущий CFE, проверьте совместимость на копии и завершите сеансы перед обновлением метаданных. Пароли, токены и выгрузки базы передавайте отдельно от исходников. Данные авторизации находятся в настройках виджета и константах базы; значения не входят в документацию.

Если откат касается изменения типа поля `Договор`, возврат старого расширения может быть несовместим с уже записанными ссылками. Надёжный путь восстановления — заранее проверенная резервная копия всей тестовой базы; простую замену CFE нельзя считать универсальным откатом. Восстановление копии теряет изменения, сделанные после неё, поэтому сначала остановите запись и сохраните текущее состояние.

## Типовые ошибки

| Симптом | Что проверить |
| --- | --- |
| HTML 404 в окне виджета | Корень `server_url`, повторный `/hs/integration`, обработчик IIS `path="*"`, публикацию сервиса расширения |
| JSON 404 заменяется HTML | IIS `httpErrors existingResponse="PassThrough"` |
| Ошибка прокси 500 | Исходное сообщение во вложенном JSON, реальный статус 1С, наличие уже созданного документа |
| 401 | Логин/пароль тестовой базы, заголовок Authorization, права пользователя |
| Нет связи снаружи | Доступность публикации по LAN, адрес сервера, правила порта и маршрутизацию; затем n8n |
| Документ есть, но не проведён | `status`, `error_reason`, остатки, реквизиты; ответ 202 допускает черновик |
| Сумма стала 1885,25 вместо 2300 | Версию CFE, обновление базы, перенос `Всего` при включённом НДС |
| Нет группы ПРОПАН | Карточку конкретного товара, `Товары.Субконто`, движения 90.01.1/90.02.1 |
| Не тот договор | UUID явного выбора, владельца и вид договора, ссылку заказа, регистр связей и версию |
| Старый PDF показывает старые суммы | PDF создан до исправления; изменения базы не заменяют вложения amoCRM автоматически |

Ошибки маршрута и ошибки данных проверяются раздельно. Локальный успешный ping не подтверждает прохождение запроса из браузера amoCRM через внешний прокси.

## Где искать данные

В 1С: документы, регистры связей `TeMa_ИдентификаторыAmoCRM_*`, регистр `TeMa_ЛогиAPI` и журнал регистрации. На веб-сервере: журналы IIS. На прокси: история выполнения соответствующего workflow n8n. В браузере: запрос, статус и тело ответа; перед передачей выгрузки сети удаляйте Authorization, токены и персональные данные.

Конкретные IP и пути исторического стенда находятся в локальной инструкции `1c-test-base/verification/WIDGET-CONNECTION.md`. Они не являются универсальной конфигурацией поставки и не проверялись на дату подготовки документации.
