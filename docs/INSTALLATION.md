# Сборка и установка

## Требования

- Node.js **>=22.12.0** и npm: Vite 8 допускает также 20.19+, но упаковщик bestzip 3 требует Node.js 22+. Комплект проверяется сборкой на доступном Node.js 24.
- Python 3 для упаковки исходников и проверки артефактов.
- Платформа 1С и совместимая конфигурация с объектами, заимствованными расширением. Сохранённые проверки выполнены на **8.5.1.1522, 32 bit**. Режим совместимости расширения 8.3.27 не означает проверку исполнения на каждой версии платформы.
- IIS и компоненты веб-публикации той же установленной платформы; доступ к n8n и amoCRM для сквозного сценария.

## Виджет

В папке `frontend`:

```powershell
npm ci
npm run build
```

Результат — `frontend/widget.zip`. В корне ZIP должны находиться `manifest.json`, `script.js`, `app.js`, папки `i18n` и `images`. Установите ZIP средствами приватной интеграции amoCRM. Сборка не выполняет установку автоматически.

| Настройка | Значение |
| --- | --- |
| `server_url` | Корень публикации, например `https://onec.example.test/test`; **без** `/hs/integration` |
| `login_1c`, `password_1c` | Учётная запись опубликованной тестовой базы |
| `n8n_url` | Хост или базовый URL n8n; код дописывает `/webhook/1c-proxy` |
| `deal_button_field` | ID поля карточки сделки для кнопки |
| `company_button_field` | ID поля карточки компании для кнопки |
| `Access_token_Amocrm` | Токен для используемых функций amoCRM/Drive |

Виджет добавляет к `server_url` путь `/hs/integration/...`. Добавленный вручную повторный префикс вызывает неверный адрес. Если `n8n_url` пуст, используется `n8n.24tema.ru`; при переносе задайте свой адрес и проверьте отдельный адрес уведомления о счёте в исходниках.

## Расширение 1С

1. Подготовьте отдельную тестовую копию, отключите ненужные обмены и фоновые задания. Сделайте резервную копию перед обновлением.
2. В Конфигураторе откройте список расширений. Для имеющегося `ИнтеграцияAmoCRM` загрузите исправленный CFE в это расширение. Не устанавливайте одновременно старый и новый варианты как два расширения с одной логикой.
3. Используйте `1c-test-base/extension/price-contract-fix/ИнтеграцияAmoCRM_цены_договоры.cfe` и обновите конфигурацию базы данных.
4. Проверьте применимость и серверный код, завершите старые сеансы и подключитесь заново.
5. Выполните приёмку из `VALIDATION.md` до переноса в рабочую базу.

Для разработки откройте или загрузите XML-исходники из `price-contract-fix/src`. Штатная последовательность Конфигуратора:

```text
/LoadConfigFromFiles "<src>" -Extension ИнтеграцияAmoCRM
/UpdateDBCfg -Extension ИнтеграцияAmoCRM
/CheckConfig -Server -ExternalConnection -Extension ИнтеграцияAmoCRM
/DumpCfg "<выходной CFE>" -Extension ИнтеграцияAmoCRM
```

Эти параметры передаются `1cv8.exe DESIGNER /F "<тестовая база>"` с авторизацией и журналом `/Out`. Не запускайте последовательность на рабочей базе для проверки сборки. Обновление типа поля заказа требует именно обновления конфигурации базы, одного копирования CFE недостаточно.

## Веб-публикация

Публикуйте HTTP-сервис расширения `TeMa_HTTPСервис`, корневой URL сервиса — `/hs/integration`. Пример ping: `https://onec.example.test/test/hs/integration/ping`. У ping нет `/v1`.

Для проверенного стенда использовались отдельный IIS site/app pool, 32-разрядный Classic pool без managed runtime, ISAPI платформы и отключённые веб-клиент/OData/лишние сервисы. В IIS обработчик публикации использует `path="*"`; настройка `httpErrors existingResponse="PassThrough"` сохраняет исходные JSON-ошибки 1С.

В `verification/Prepare-TestPublication.ps1` и `Enable-TestLan.ps1` находятся скрипты конкретного локального стенда. Перед повторным использованием изучите их параметры и пути; изменение IIS/межсетевого экрана требует прав администратора. Перенаправление роутера не является частью сборки проекта.

Прокси должен передавать метод, тело JSON и `Authorization` к адресу `X-1C-Url`, поддерживать загрузку PDF и разрешать требуемые браузерные заголовки. На новом стенде отдельно проверьте формат ответа: n8n может оборачивать JSON в массив и ошибки 1С — во вложенную ошибку.

Исходная выгрузка тестовой базы восстанавливается по отдельной инструкции `1c-test-base/README.md`. В комплект исходников она не входит; XML расширения не заменяет конфигурацию и данные базы.
