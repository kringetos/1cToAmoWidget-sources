# Расширение: цена, договор и номенклатурная группа

Файл установки: `ИнтеграцияAmoCRM_цены_договоры.cfe`.
Полные исходники расширения: `src` (XML метаданных и пять BSL-модулей).
Контрольные суммы: `manifest.json`.

Этот вариант включает перенос номенклатурной группы, корректный перенос суммы с НДС в счёт/УПД/спецификацию и общий выбор договора с сохранением старых строковых значений заказа. Устанавливается обновлением существующего расширения `ИнтеграцияAmoCRM` и обновлением конфигурации базы.

Сохранены успешные результаты четырёх сценариев цены и договора и четырнадцати регрессий на платформе 8.5.1.1522 от 26.10.2026. Они не подтверждают исправление ранее созданных пользовательских документов или полный сквозной запуск нового варианта из amoCRM.

Подробная документация в корне проекта: `docs/INSTALLATION.md`, `docs/BUSINESS-RULES.md`, `docs/VALIDATION.md`. Исторические документы автоматически не изменяются.
