# Интеграция 1С и amoCRM

Виджет amoCRM для работы с контрагентами, заказами, счетами, УПД и договорами в 1С. Серверная бизнес-логика находится в расширении `ИнтеграцияAmoCRM`; виджет обращается к опубликованному HTTP-сервису через прокси n8n.

## Актуальные компоненты

| Компонент | Путь | Назначение |
| --- | --- | --- |
| Виджет 1.0.191 | `frontend/src`, `frontend/widget` | React-интерфейс и оболочка amoCRM |
| Исправленное расширение | `1c-test-base/extension/price-contract-fix/src` | Полная XML-выгрузка расширения, включая BSL и метаданные |
| Файл установки | `1c-test-base/extension/price-contract-fix/ИнтеграцияAmoCRM_цены_договоры.cfe` | Исправления цены, договора и номенклатурной группы |
| Проверки | `1c-test-base/verification` | Сценарии BSL и сохранённые результаты |
| Старый вариант расширения | `1c-test-base/extension` вне `price-contract-fix` | Исторический вариант с исправлением группы |
| Python backend | `backend/main.py` | Заготовка FastAPI; не заменяет рабочий HTTP-сервис 1С |

**Для новой установки используйте CFE из `price-contract-fix`.** Старый CFE и первоначальный отчёт относятся к предыдущему этапу. Расширение не выполняет массовое исправление ранее созданных документов.

## Подготовка передачи

Готовый комплект: [архив исходников и документации](releases/2026-11-23/1c-amocrm-2026-11-23.zip), [SHA-256](releases/2026-11-23/1c-amocrm-2026-11-23.zip.sha256).

```powershell
python tools/prepare_sources.py
```

Команда создаёт самостоятельную папку `deliverables/1c-amocrm-2026-11-23`. После сборки виджета и упаковки по инструкции [SOURCE-DELIVERY](docs/SOURCE-DELIVERY.md) получается архив для передачи разработчику. Базы данных, пароли и установленные зависимости в комплект не включаются.
